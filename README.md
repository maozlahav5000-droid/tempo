# TEMPO

סביבת תרגול מוזיקלית בעברית הכוללת מטרונום חזותי, ניהול שיעורים, הערות עשירות ומאגר קובצי תווים לפי חימום ותרגול.

## יכולות עיקריות

- מטרונום עם BPM ניתן להקלדה, משקלים מוזיקליים וקיצורי 50/60 BPM.
- מעגל פעימות בסגנון Simon וחלונית מטרונום צפה שניתנת להזזה ולמזעור.
- ניהול שיעורים והערות עם תמיכה ב־Ctrl+B, Ctrl+U ו־Ctrl+I.
- העלאת כמה קובצי PDF או תמונות יחד, תיקיות מותאמות אישית ותצוגת תווים מוגדלת.
- ממשק RTL מותאם למחשב, לטלפון ולמצב אופקי.
- שמירת נתונים באמצעות Cloudflare D1 וקבצים באמצעות Cloudflare Workers KV.
- גישה לענן מוגנת בקישור פרטי וב־cookie מאובטח; הסוד אינו נשמר ב־GitHub.

## הרצה מקומית

נדרשת גרסת Node.js ‏22.13 ומעלה.

```bash
npm install
npm run build
npm run dev
```

האתר המקומי נפתח בכתובת `http://127.0.0.1:3000/`.
